Lemmy v0.10.0 Release Written by @dessalines and @nutomic, 2021-04-05 Changes Since our last release in February, we've had ~150 commits to Lemmy. The biggest changes, as we'll outline below, are a split of Lemmy's user tables into federated and local tables, necessitating a v3 of Lemmy's API, federated moderation, i18n support in join.lemmy.ml, and lots of back-end cleanup. Lemmy Server General Rewrote config implementation, finally allowing us to use newer Rust versions.
